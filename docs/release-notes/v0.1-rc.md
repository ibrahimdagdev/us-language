# US v0.1 Release Candidate

## Özet

US, Türkçe sözdizimli bir programlama dilidir. v0.1 adayı yorumlayıcı, .NET derleyici backend (`DotNetEmitBackend`), CLI, proje sistemi, bellek dosya/HTTP/veritabanı konakları ve araç sözleşmelerini içerir.

Bu belge tahmin yazmaz. Derleyici matrisi ve bilinen sınırlar esas alınır.

## Derleyici sözleşmesi

Kaynak: `docs/compiler-parity.md`.

- **SUPPORTED:** production-supported compiled yüzey; interpreter parity doğrulanmış.
- **PARTIAL:** production-supported değil; sessiz yanlış derleme yasak.
- **DEFERRED / N/A:** örn. `ref`/`çıktı` emit yok; SQL Server / Kestrel / remote registry.

`us derle` üretilen assembly Evaluator / ProgramRunner / runtime parse-rebind kullanmaz.
