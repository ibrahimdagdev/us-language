# US v0.2.0 — Release Notes

**Product version:** 0.2.0  
**Status:** stable release

## Highlights

- **`ref` / `çıktı` compiler parity** for locals and parameters (ByRef IL)
- **Nested JSON** / `liste<model>` compiler parity with US1541 / US1529 fidelity
- **Async instance methods** with `bu` / ThisSlot seeding
- **Database query compiler parity** including flat `birlikte`
- **SQL Server provider** (`Us.Data.SqlServer`) with parameterized CRUD, transactions, schema sync
- **Real Kestrel hosting** (`Us.Hosting`) over compiled route dispatch
- **Outbound HttpClient transport** (optional; fake transport remains CI default)
- **Deterministic local package resolution** (`paketler/{name}/{version}`)
- **Package archive hardening** (US1554 zip-slip, US1558 duplicates, optional SHA-256 US1559)

## Verified backend path

```text
US source → Compiler → .NET → Kestrel → real TCP → SQL Server → JSON
```

## Acceptance proof (Memory)

`samples/BackendAcceptance` compiles to .NET, listens on real Kestrel TCP, stores users in Memory DB, and serves JSON over `POST /kullanicilar` and `GET /kullanicilar`.

Route-parameter `GET /{id}` with in-controller Memory DB `filtrele` capturing the route local is not part of the release acceptance sample (compiler limitation on that capture path); route params themselves are covered by HTTP error/isolation suites.

## SQL Server live status

Provider is **implemented, unit-validated, and live-validated** on a real SQL Server instance before this release.

Live acceptance covered:

- real SQL Server CRUD
- parameterized injection resistance (values such as `O'Brien` and SQL-looking strings treated as data)
- real `SqlTransaction` commit / rollback / error rollback
- filter / sort through `SqlServerBackend`
- flat `birlikte`
- full-stack path: US → Compiler → .NET → Kestrel → TCP → SQL Server → JSON

CI / default `dotnet test` still skips live SQL when `US_TEST_SQLSERVER_CONNECTION` is unset; that early-return is intentional and is not a substitute for the separate live gate already completed for v0.2.0.

## Known limitations

- Public package registry server not available
- Exact package versions only (no SemVer ranges / lockfile)
- HTTPS / certificate convenience layer deferred
- Field `ref`/`çıktı` targets and async+ByRef remain US1900-gated
- Static type-level `afonksiyon` emit remains partial where previously deferred
- Deeper table-field validation (length/unique/range) remains partial
- Nested `birlikte` remains rejected (US0863)
