## 4. `ref` / `çıktı`

### 4.1 Layer status

| Layer | Status | Evidence |
| --- | --- | --- |
| Lexer | SUPPORTED | `Keywords.cs`: `ref`, `çıktı` |
| Parser / AST | SUPPORTED | `ParameterSyntax.Modifier`, `ArgumentSyntax.modifier` |
| Binder | PARTIAL | Lvalue check US0838; `çıktı` definite assign US0839; gaps below |
| Interpreter | SUPPORTED | Shared `Cell` alias; US1511 on unread `çıktı` after normal return |
| Compiler | DEFERRED | All params `UsValue` by value; no ByRef / `ldarga` / `stind` |
| Diagnostics | SUPPORTED (bind/runtime) | US0838, US0839, US0816, US1501, US1511 |
| Tests | PARTIAL | Milestone6/8/11 happy paths; missing US0839/US1511/field/index/parity |
| Docs | SUPPORTED | `language-spec.md` §9; `compiler-parity.md` DEFERRED |

### 4.2 Semantic answers (verified, not invented)

| Question | Spec | Actual binder/runtime |
| --- | --- | --- |
| Must `ref` args be initialized? | Yes | Binder does **not** enforce (assignment-target path skips US0816). Runtime: US1501 if callee reads. |
| Must `çıktı` be assigned before return? | Yes | US0839 (binder) + US1511 (runtime). Not required on throw. |
| Fields as targets? | Implied by “değişken” + FieldSymbol | Yes (binder + interpreter `Alias`) |
| Properties? | N/A | No property symbols in US |
| Indexed collection elements? | Not specified as allowed | Rejected US0838 |
| Aliasing | Shared mutable location | Yes — same `Cell`; double-`ref` same local works |
| Nullable | Same as other params | `EnsureCanStore` / nullable flags |
| Value vs reference types | Cell aliasing | Value types: shared cell; object refs: shared cell holding reference |
| Nested ref forwarding | Yes | `ParameterSymbol` targets work |
| Async + `ref`/`çıktı` | Not restricted in language | Compiler: CLR async + ByRef is hard — **recommend reject** with diagnostic |

### 4.3 US1511 exact behavior

- Code: `UsRuntimeCodes.OutputRuntime` = **US1511**
- Fired in interpreter after normal function return if any `IsOut` param cell still `!IsAssigned`
- Caveat: alias does not clear `IsAssigned`; if caller var was already assigned and callee never writes, US1511 may not fire (US0839 usually catches at bind time)

### 4.4 Critical compiler risk

Today `DotNetEmitBackend` copies all arguments by value (`Ldarg` → local). Compiling `ref`/`çıktı` would produce **wrong semantics** (silent incorrectness). Parity contract forbids this.

**M20 gate (required before any other emit work on this feature):** reject `IsRef`/`IsOut` with structured **US1900** (or specific code) until ByRef emit lands.

### 4.5 IL strategy (plan only)

1. Parameter types: `typeof(UsValue).MakeByRefType()` for `IsRef`/`IsOut`; optional `ParameterAttributes.Out` for `çıktı`.
2. Prolog: do **not** copy ByRef into by-value local; keep managed pointer or `Ldobj`/`Stobj` for `UsValue`.
3. Call sites:
   - Local/param → `Ldloca`
   - Field → phase 1: US1900 until object model supports addressable `UsValue` slots (or heap cell API)
   - Index → keep unsupported (match binder)
4. Reads/writes of ref/out params: `Ldarg` (ptr) + `Ldobj`/`Stobj` `UsValue`.
5. Async: ban `afonksiyon` + ByRef params (diagnostic).
6. Tighten binder: enforce `ref` initialized; match call-site modifiers in overload `Matches`; `CheckOutputs` on expression-bodied functions.
7. Parity: port Milestone6 cases through `ParityHarness`.

Do **not** expose C# `ref`/`out` syntax to US users.

| Dictionary | PARTIAL elsewhere | PARTIAL | Not JSON-first |

| Missing required US1528 | SUPPORTED | SUPPORTED | |
| Unknown field US1527 | SUPPORTED | SUPPORTED | |

| Malformed US1535 | SUPPORTED | SUPPORTED | |

### 5.2 Lowering design (preferred)

- Keep **symbol-driven shape encoding** in the emitter (`UsEmitJson.EncodeShape`).
- Compiled code calls **stable `Us.Runtime` helpers** (`UsEmitJson.Write` / `Read`), not raw `System.Text.Json` with divergent rules.
- Observable US rules must match interpreter: unknown fields, required fields, cycles, null-into-non-nullable.
- Fix field-level null path so diagnostics stay **US1541**, not US1500.
- Promote nested / `liste<model>` to SUPPORTED only after parity harness tests.

### 5.3 Main gap

Parity proof + US1541 field-path fidelity for nested / list-of-model cases already partially implemented in runtime.

## 6. Async instance methods

### 6.1 Status

| Capability | Interpreter | Compiler |
| --- | --- | --- |
| Free / top-level `afonksiyon` | SUPPORTED | SUPPORTED |
| Top-level `bekle` | SUPPORTED | SUPPORTED |

| Instance `afonksiyon` (sınıf/servis/model) | SUPPORTED | **PARTIAL** — bodies excluded |
| Static type-level `afonksiyon` | Likely bound | Gap — not in freeFunctions nor instanceMethods |
| Virtual/override async | Dispatch OK | Not emitted (filtered out) |
| Captured `bu` | SUPPORTED | PARTIAL — `ThisSlot` not seeded for async trampoline |

### 6.2 Exact compiler limitation

```csharp
// DotNetEmitBackend.cs — instanceMethods filter includes:
&& !item.IsAsync
```

Call sites for missing instance methods report US1900: *“Örnek metod '{name}' henüz derlenmiyor.”*

### 6.3 Lowering architecture

Current architecture uses `UsEmitAsync` / `UsAsyncBox` (Task boxes in CLR, not source `Task`). Preserve this — do **not** require a full C#-style state machine rewrite if extending Box + MoveNext for instance methods works.

**Required work:**

1. Remove `!item.IsAsync` from instance method emit filter.  
2. Emit async instance bodies with `self` as first `UsValue` arg (existing sync pattern).  
3. Seed `ThisSlot` / `bu` for async trampoline.  
4. Call sites: Box instance async methods like free async.  
5. Parity tests: service/controller-style instance `afonksiyon` (see `samples/WebApi/ana.us`).

### 6.4 OOP edge cases in scope

Include only if grammar/runtime already supports them: `bu`, sync virtual/override interaction, exceptions through await, nullable returns.  
Do **not** expand to CLR-only features US does not model.

## 7. Table / query / `birlikte`

### 7.1 Semantics of `birlikte` (authoritative)

From `docs/language-spec.md` § “İlişki yükleme”:

- **Eager relationship include**, not SQL JOIN / not row-multiplying join.
- Result shape remains `liste<BaseRow>` (e.g. `liste<Sipariş>`).
- Flat member path only: `^.kullanıcı` OK; nested `^.kullanıcı.adres` → **US0863**.
- Missing member → **US0862**.
- No text SQL generated; bound tree + in-memory plan today.

Interpreter: related models stored as FK ints on insert; `tümü()` materializes then hydrates includes (`Evaluator.Database.cs` / `UsTableQuery.Include`).

### 7.2 Feature matrix

| --- | --- | --- | --- | --- | --- | --- |
| `ekle` | Yes | Yes | Yes | None | SUPPORTED | — |
| `tümü` | Yes | Yes | Yes | None | SUPPORTED | — |
| `filtrele` | Yes | Yes | Yes | None | SUPPORTED | Memory provider; SQL = M25 |
| `sırala` / `tsırala` | Yes | Yes | Yes | None | SUPPORTED | Memory provider; SQL = M25 |

## 8. SQL Server provider

### 8.1 Current architecture

| Piece | Reality |
| --- | --- |
| Interface | Interpreter `IDatabaseProvider` + runtime `IUsDatabaseBackend` / `UsQueryPlan` |
| Concrete | `MemoryDatabase` + `UsEmitDatabase` (memory) + `SqlServerBackend` |
| Schema sync | `.us-schema.json` + Option C SQL inspect/additive DDL; destructive US1550/`onay` |
| US1550 | Destructive steps without `onay` blocked (JSON + SQL) |
| SQL text | Spec: “Metin SQL üretilmez” for user-facing query language |
| NuGet | `Microsoft.Data.SqlClient` in `Us.Data.SqlServer`; CPM via `Directory.Packages.props` |

### 8.2 Recommended design

**Driver:** `Microsoft.Data.SqlClient` (fits .NET 10; add via `Directory.Packages.props` when deps are introduced).

**Not an ORM.** Map US bound query ops to parameterized commands.

Widen shared abstraction usable by interpreter host and emit runtime:

1. Connection factory / lifetime from `bağla` / config  
2. Transactions → `SqlTransaction` (keep single-level = language rule)  
3. Parameterized CRUD + filter/sort materialization  
4. `birlikte` → second query or JOIN **internally** (user still writes `birlikte`)  
5. Model materialization to `UsValue` / `UsEmitObject`  
6. Schema inspection + optional DDL sync behind US1550  

Prefer new project boundary e.g. `Us.Data.SqlServer` so Core stays free of SQL deps.

### 8.3 Schema sync recommendation

**Option C — phased:**

| Phase | Behavior |
| --- | --- |
| v0.2.0a | Keep `.us-schema.json` history; add read-only SQL Server schema **inspection** |
| v0.2.0b | Additive DDL only (`CreateTable`, `AddColumn`) behind explicit sync |
| Later | Destructive DDL still requires `onay` / US1550; never auto-destructive |

Never automatically drop/narrow without explicit approve semantics.

### 8.4 Safety requirements

- Parameterized SQL only; no user-value string concatenation  
- Deterministic mapping  
- Transaction correctness + disposal of connection/command  
- Cancellation where architecture supports it  
- Useful diagnostics; **no secrets in logs** (`SecretRedactor` already exists)  
- Zip/path rules unchanged

### 9.2 Recommended architecture

Thin adapter over existing pipeline:

```
Kestrel / WebApplication
  → map HttpContext → UsHttpRequest
  → UsWebHost / UsEmitHttp.DispatchAsync (US RouteTable, DI scope, binding)
  → write status / headers / body
```

- Do **not** leak ASP.NET MVC/minimal-API syntax into US source.  
- US remains: `kontrolcü` / `rota GET ...`.  
- Outbound: real `HttpClientTransport : IHttpTransport`; keep Fake for tests.  
- Keep `US_TEST_ROUTE` for parity without ports.

### 9.3 HTTP behavior in scope (minimal)

Verbs already bound: GET, POST, PUT, PATCH, DELETE.  
Plan: route matching, path params, query values, JSON body, status helpers, 404/400/401/403/409/415 as already modeled.  
Do **not** invent middleware ecosystems.

### 9.4 Server lifecycle (minimal v0.2.0)

Startup, port binding, Ctrl+C / graceful shutdown, basic logging/exceptions.  
Not a full ASP.NET replacement.

## 10. Package system

### 10.1 Current (M27)

| Behavior | Detail |
| --- | --- |
| Manifest | `us.proje` — `paket "Name" sürüm "x.y.z"`; exact versions only; case-sensitive names |
| Default version | `1.0.0` when sürüm omitted on `paket ekle` |
| Identity | `Name@version` (ordinal); conflicts → US1556; cycles → US1557 |
| Local cache | `paketler/{name}/{version}/` under project root |
| Resolution | `PackageResolver` — offline, deterministic; soft-skip missing (ekle without kur); `ResolveRequired` for strict |
| Compile integration | Resolved `*.us` sources merge into project `SourcePaths` (Binder/Compiler; no interpreter fallback) |
| `us paket ekle <ad> [sürüm]` | Idempotent append of exact `paket` line |
| `us paket kur <dosya.zip>` | Extract via `PackageArchive` → cache; optional SHA-256 (US1559) |
| `PackageArchive` | Zip-slip US1554; duplicate normalized paths US1558; staging then finalize |
| `al` | Import alias only; does **not** download packages |
| Registry | `PackageRegistryClient` stubs only (HTTPS metadata/download hooks); **no public registry server** |

### 10.2 v0.2 limitations

No SemVer ranges, no lockfile, no transitive solver beyond exact deps in package `us.proje`, no install scripts, no signing PKI, no online registry. Local/cache resolution works offline.

### 10.3 Remote registry foundation (client-first)

Client hooks for future registry URL + SHA-256 integrity.  
Reuse `PackageArchive` + US1554.  
**Do not** build an online registry server in v0.2.0.

## 16. Exit criteria

### Compiler parity

- `ref`/`çıktı`: ByRef emit for locals/params **or** explicitly narrowed with diagnostics; no silent wrong compile.  
- Nested JSON / `liste<model>`: interpreter/compiler parity for documented cases.  
- Async instance methods: documented cases compile and run.  
- Table/query: documented compiler cases including `birlikte` (flat) compile.  
- No interpreter fallback in emitted assemblies.

### Backend

Minimal acceptance application (design only for Phase 0):

```
.us source
→ Lexer → Parser → Binder → Compiler → real .NET IL → executable
→ Kestrel
→ HTTP route
→ SQL Server
→ JSON response
```

Scenarios:

- `GET /kullanicilar/{id}` — read row, return JSON  
- `POST /kullanicilar` — accept JSON, insert row  

US runtime helpers allowed. Interpreter fallback forbidden.
